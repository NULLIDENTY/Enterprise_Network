Stage 1 — Functional enterprise LAN
- [ ] VLANs and trunking
- [ ] Inter-VLAN routing
- [ ] DHCP and DNS
- [ ] ACL-based department access


Stage 2 — Redundant campus
- [ ] Two Layer 3 core switches
- [ ] HSRP
- [ ] Rapid PVST+
- [ ] LACP EtherChannel


Stage 3 — Dual-ISP connectivity
- [ ] Two ISP routers and two edge routers
- [ ] Default and floating static routes
- [ ] NAT/PAT
- [ ] Upstream failure detection and backup routing


Stage 4 — Advanced routing
- [ ] OSPF inside the enterprise
- [ ] eBGP between enterprise and ISP routers, if supported
- [ ] Route filtering and route preference


Stage 5 — Enterprise security
- [ ] DMZ and server access restrictions
- [ ] SSH management and port security
- [ ] DHCP snooping / DAI where supported
- [ ] Optional ASA firewall


Stage 6 — Operations and proof
- [ ] Syslog, NTP and available monitoring
- [ ] Failure and recovery tests
- [ ] Configuration backups
